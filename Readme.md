## Планы

### Backend

- Проверить конкурентные запросы на PostgreSQL.
- Добавить ограничение частоты гостевых записей перед публичным запуском.

### Frontend

- Проверить интерфейс с реальными пользователями и уточнить удобство расписания.
- Расширять браузерные проверки по мере появления новых сценариев.

## Запуск приложения

Установка зависимостей из pyproject.toml:

```powershell
python -m pip install -e .
```

Запуск сервера:

```powershell
python -m uvicorn app.main:app --reload
```

Сайт открывается по адресу http://127.0.0.1:8000/. Дополнительный сервер для frontend,
React и установка npm-зависимостей не нужны. `/health` возвращает статус приложения,
документация API остаётся на `/docs`.

Для первого знакомства создай аккаунт репетитора, открой время в кабинете и скопируй
ссылку на свою страницу. Открой её в другом браузере или после выхода из аккаунта,
чтобы записаться гостем либо учеником. Для записи без аккаунта понадобится ссылка из письма;
без SMTP письмо выводится в терминал сервера.

В хедере — `/` (Главная), `/features` (Возможности) и «Мой кабинет» после входа.
На телефонах меню раскрывается кнопкой. Поиск репетиторов доступен из кабинета ученика
и главной страницы; помощь — из кабинетов и футера. Старые `/for-tutors`, `/for-students`,
`/tutors` и `/help` сохранены по прямым ссылкам.
На странице «Ученикам» можно открыть полученную ссылку репетитора; в помощи есть поиск по ответам.
Каталог `/tutors` показывает публичные профили из существующего `GET /api/v1/tutors`:
поиск по имени, предмету и описанию, фильтр по предмету, переход к расписанию.
Поиск и предметы разнесены по отдельным блокам; есть быстрые кнопки предметов,
сортировка по имени и карточки с кратким описанием преподавателя.
Кнопки поиска есть также в кабинете ученика и во вкладке «Мои репетиторы».
Предметы берутся из единого списка `app/core/subjects.py` через `GET /api/v1/tutors/subjects`.
Репетитор выбирает предмет из списка при регистрации и в профиле. Новые произвольные
названия не принимаются; старые нестандартные значения сохраняются. Чтобы добавить
новый предмет, дополни `SUBJECTS` и перезапусти сервер. Изменение списка не требует Alembic.
Справа от «Выйти» отображаются имя из профиля и пустое место под аватарку.
Нажатие на имя открывает профиль; сохранённое новое имя сразу обновляется в шапке.
`GET /api/v1/users/me` возвращает дополнительное поле `name`; загрузка аватарок пока не реализована.

Остальные страницы: `/login`, `/register`, `/tutor/dashboard`, `/student/dashboard`,
`/t/номер`, `/confirm` и `/cancel`. Ссылки подтверждения и отмены должны содержать токен из письма.
Вход хранится в текущей вкладке браузера. Расписание репетитора использует пояс его профиля,
ученик может выбрать пояс отображения на странице записи. Обе цветовые темы сохранены.

В кабинете репетитора вкладка «Ученики» собирает собственные записи по ученикам:
поиск по имени и email, фильтры аккаунтов и гостей, ближайшие занятия и история.
Гостевые записи объединяются по email отдельно от зарегистрированных учеников.
В кабинете ученика вкладка «Мои репетиторы» показывает преподавателей из его записей,
позволяет искать по имени и предмету, просматривать историю и записываться повторно.
Из карточек обеих ролей можно отменить предстоящее занятие. Списки строятся через
существующие `/api/v1/bookings/tutor` и `/api/v1/bookings/my`; новые таблицы не нужны.
Число «Прошло» означает записи с закончившимся временем, а не подтверждение посещения.

Кабинеты открываются на «Обзоре»: сводка, ближайшее занятие и быстрые действия.
У репетитора в сводке — ученики, уроки сегодня, ожидаемая оплата и уроки на текущей
календарной неделе (понедельник–воскресенье). Уроки считаются по подтверждённым записям
в часовом поясе профиля; число учеников соответствует вкладке «Ученики», включая гостей.
Карточка «Ждут оплаты» пока показывает «—»: учёт оплат ещё не подключён.
Разделы находятся в боковом меню; на телефоне меню располагается над содержимым.
Профиль в обоих кабинетах находится в отдельной группе «Настройки».

В кабинете ученика обзор показывает ближайший урок, текущую неделю и предметы
из его записей. Вкладка «Моя неделя» позволяет выбирать дату, переключать недели,
возвращаться к сегодняшнему дню и отменять запись. Время отображается в часовом
поясе браузера; отменённые записи остаются в истории. «Домашние задания» и
«Материалы» выделены в отдельные учебные разделы с меткой «Скоро»: обмен файлами,
выдача заданий и обратная связь пока не подключены.

Меню репетитора разделено на «Работа», «Учебный процесс», «Деньги» и «Настройки».
Добавлены вкладки «Домашние задания», «Оплаты и абонементы» и «Отчёты»,
а на обзоре — блок домашних заданий с переходом. Новые разделы пока показывают
«Скоро»: выдача заданий, учёт оплат, абонементы и финансовые отчёты ещё не подключены.

В обоих кабинетах есть SVG-иконки и дополнительные акценты: приглушённый голубой
для учебных разделов, терракотовый для финансов. Золотой остаётся основным цветом
действий. Оттенки адаптированы к светлой и тёмной темам. На телефоне меню —
одна прокручиваемая строка; выбранная вкладка автоматически появляется в видимой области.
Записи и контакты отображаются компактными строками. Большая форма открытия ссылки
вынесена в раскрываемый блок вкладки «Мои репетиторы».
Регистрация проходит три шага: роль, контактные данные, проверка перед созданием аккаунта.
Можно вернуться назад без потери введённых данных; пароль в сводке не показывается.
Шаги отображаются крупными кнопками перехода. Проверка данных обязательна перед
переходом на последний шаг, независимо от способа перехода.

Проверка подключения к PostgreSQL (после настройки `DATABASE_URL` в локальном `.env`):

```powershell
python -m app.db.check
```

Создание таблиц в пустой PostgreSQL БД:

```powershell
python -m alembic upgrade head
```

Если таблицы уже существуют, удалять БД не нужно. Для первого подключения выполни
`python -m alembic -x check_schema=true stamp 0001`: команда проверит совпадение схемы
и отметит начальную версию без изменения данных. При несовпадении остановится.

Отправка писем из очереди уведомлений:

```powershell
python -m app.services.email_worker
```

Отладочные списки пользователей, учеников, слотов, записей и уведомлений, а также
`POST /api/v1/notifications/process` доступны без входа при `DEBUG=true`.
При `DEBUG=false` они возвращают 404. Методы `/me`, `/my` и `/tutor` требуют обычного входа.

В `.env` задай `PUBLIC_BASE_URL` — адрес backend для ссылок в письмах
(локально `http://127.0.0.1:8000`). Без SMTP письма выводятся в консоль.
Гостевая запись имеет статус `pending` и ожидает подтверждения 15 минут
(`GUEST_CONFIRMATION_MINUTES`). После подтверждения запись становится `active`, слот — `booked`.
В письме есть ссылки подтверждения и отмены с оформленными страницами и кнопками действия.
Запись авторизованного ученика сразу активна.

Просроченная гостевая бронь освобождается при запросе расписания, новой записи на её слот
или запуске email-воркера. Воркер выполняет один проход; для очистки даже без посетителей
запускай его раз в минуту через планировщик задач. Удаление слота с историей закрывает его
со статусом `cancelled`, сохраняя прошлые записи.

Проверки backend на временной SQLite, без чтения `.env` и отправки настоящих писем:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Эти проверки не проверяют блокировки строк PostgreSQL.

Проверки JavaScript (Node.js 22+; для обычного запуска сайта Node.js не требуется):

```powershell
node --test tests/frontend.test.mjs
```

Браузерная проверка использует отдельную временную SQLite и тестовые аккаунты, не читает `.env`
и не отправляет письма. Запусти в одном терминале:

```powershell
.\.venv\Scripts\python.exe -m uvicorn frontend_preview:app --app-dir tests --host 127.0.0.1 --port 8765 --no-access-log
```

Затем в другом терминале: `node tests/frontend_browser.mjs`. Скрипт использует установленный
Google Chrome (при другом расположении укажи `CHROME_PATH`), проверяет меню, новые страницы,
поиск в помощи, открытие ссылки репетитора, регистрацию, запись, вкладки учеников и репетиторов,
поиск и фильтры кабинетов, обзоры, боковое меню, шаги регистрации, повторную запись,
отмены обеими ролями, мобильную вёрстку
и сохраняет скриншоты в игнорируемый `tests/artifacts/`.
После проверки останови тестовый сервер через Ctrl+C.
