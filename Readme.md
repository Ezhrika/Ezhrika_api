# SmartConsult_api

Реворк части бэкенда репозитория [SmartConsult_backend](https://github.com/Mr-tvorozhok/SmartConsult_backend) на FastAPI.

Фактически, это моё первое знакомство с FastAPI.

Данный репозиторий был взят за основу для проекта акселератора. Дальнейшая разработка проекта будет вестись в отдельном репозитории, поэтому данный репозиторий оставлен без дальнейших изменений.
