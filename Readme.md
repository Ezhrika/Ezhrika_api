## Планы

### Backend

- Настроить Alembic и создать таблицы в PostgreSQL.
- Добавить регистрацию и вход для репетиторов и учеников.
- Реализовать создание и редактирование собственных профилей.
- Добавить управление свободным временем и проверку пересечений.
- Реализовать запись и отмену занятий, защитить от двойной записи.
- Ограничить доступ к чужим данным.
- Добавить email-подтверждения и уведомления об отмене.

### Frontend

- Создать страницы регистрации и входа.
- Сделать кабинет репетитора: профиль, свободное время и записи.
- Сделать кабинет ученика: предстоящие занятия и отмена записи.
- Создать публичную страницу репетитора с выбором времени.
- Подключить страницы к API и показывать результат действий и ошибки.

## Запуск приложения

Установка зависимостей из pyproject.toml:

```powershell
python -m pip install -e .
```

Запуск сервера:

```powershell
python -m uvicorn app.main:app --reload
```

Проверка подключения к PostgreSQL (после настройки `DATABASE_URL` в локальном `.env`):

```powershell
python -m app.db.check
```

Сайт с документацией (port 8000!)
```http://127.0.0.1:8000/docs#/```
