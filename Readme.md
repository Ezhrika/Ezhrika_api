## Возможности

- Регистрация, JWT-авторизация, профили учеников и репетиторов.
- Каталог преподавателей, расписание, запись на занятия и отмена.
- Гостевая запись с подтверждением по email, личные кабинеты и история записей.

Домашние задания, материалы и учёт оплат пока не подключены.

## Запуск приложения

### Требования

Python 3.11+ и PostgreSQL. Для проверок frontend дополнительно нужны Node.js 22+ и Google Chrome.
Команды выполняются из корня проекта в PowerShell.

### Установка зависимостей

Создание окружения, его активация и установка зависимостей из `pyproject.toml`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
```

### Настройка окружения

При первом запуске создайте `.env` из примера:

```powershell
Copy-Item .env.example .env
```

Заполните параметры под своё окружение:

| Параметр | Что указать |
| --- | --- |
| `DATABASE_URL` | Подключение к своей PostgreSQL БД: пользователь, пароль, адрес, порт и имя БД |
| `SECRET_KEY` | Собственный секретный ключ для подписи JWT |
| `PUBLIC_BASE_URL` | Адрес приложения для ссылок в письмах; локально — `http://127.0.0.1:8000` |
| `SMTP_*` | Параметры почтового сервера; без них письма выводятся в консоль |
| `DEBUG` | `false` для обычной работы; `true` включает отладочные методы |

### База данных

Проверка подключения по настройкам из `.env`:

```powershell
python -m app.db.check
```

Создание таблиц в новой БД и применение миграций:

```powershell
python -m alembic upgrade head
```

Если таблицы уже существуют без истории Alembic, сначала проверьте схему и отметьте начальную миграцию. Команда не меняет таблицы и остановится при несовпадении схемы.

```powershell
python -m alembic -x check_schema=true stamp 0001
```

### Сервер

Запуск приложения с автоматической перезагрузкой при изменении кода. FastAPI обслуживает и API, и frontend:

```powershell
python -m uvicorn app.main:app --reload
```

Адреса: [сайт](http://127.0.0.1:8000/), [документация API](http://127.0.0.1:8000/docs), [состояние приложения](http://127.0.0.1:8000/health).

### Почтовые уведомления

Обработка очереди писем и освобождение просроченных гостевых броней:

```powershell
python -m app.services.email_worker
```

Воркер выполняет один проход. Для регулярной обработки настройте запуск раз в минуту через планировщик задач.

### Тесты

#### Backend

Установка тестовых зависимостей и запуск проверок API, страниц и миграций:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[test]"
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют временную SQLite, не читают локальный `.env` и не отправляют письма. Блокировки PostgreSQL требуют отдельной проверки.

#### JavaScript

Проверка логики frontend встроенным тестовым модулем Node.js:

```powershell
node --test tests/frontend.test.mjs
```

#### Браузер

В первом терминале запустите сервер с временной БД и тестовыми аккаунтами:

```powershell
.\.venv\Scripts\python.exe -m uvicorn frontend_preview:app --app-dir tests --host 127.0.0.1 --port 8765 --no-access-log
```

Во втором терминале запустите проверки интерфейса в Chrome:

```powershell
node tests/frontend_browser.mjs
```

Скриншоты сохраняются в `tests/artifacts/`. При нестандартной установке Chrome укажите путь в `CHROME_PATH`.
После проверки остановите тестовый сервер сочетанием Ctrl+C.
